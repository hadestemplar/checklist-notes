# 清单体笔记 · 数据包 v1.1（操作手册型）

> 用途：把任意素材（会议记录 / 课程笔记 / 访谈稿 / 灵感）加工成**清单体笔记**，按档位判定 → 执行 → 自检。
> 来源底稿：`抓课包Skill\output\清单体笔记法\00-底稿.md`（52781 B / 532 行，2026-10-28）
> 适用对象：Agent。用户丢素材给你，你按本手册产出笔记，不需要原课。
> 本包不含落地建议、不含打分表；所有数字与术语可回溯到 §8。

---

## 0 怎么用（三步）

1. **判档**：拿 §2 的四问定目标档位（L2–L6），档位决定用 §4 里哪一组规则。
2. **执行**：按 §3 的 S1→S6 顺序做，不要跳步（S5 精简在 S4 加标题之后，顺序反了要重做）。
3. **自检**：走 §5 清单，任一条不过就回对应步骤；过完再交付。

---

## 1 触发判定

**用**：输入 ≥50 字、有信息点需要留存/复用；用户说"整理成笔记""记一下""做成清单体"。

**不用**：
- 只要摘要/翻译/润色 → 不是笔记任务。
- 要逐字稿 → 违反 §2 禁区，直接告知"笔记不记逐字稿"。
- 素材是纯图片且读不出结构 → 先解决取字问题（原图切块读），不要凭空补。

---

## 2 开工前四问（30 秒，答完再动手）

**Q1 这份笔记将来给谁用、用来干什么？** → 定档位。价值序（原话，`00-底稿.md:269`）：
`不困 < 加深印象 < 备忘回顾 < 多人协作 < 内化吸收 < 实时建模`
只给自己回头看 → L2；要给别人看 → L3；要变成自己的判断 → L4/L5；现场就要出稿 → L6。

**Q2 素材属于哪种场景？** → 定故事线（§4 3-2）：
会议/启动会→时间线或关键要素；访谈→STAR 或问题解决；课程→经典方法论；复盘→事实洞察/目标取舍。

**Q3 素材完整吗？** → 决定缺口怎么标：
有录音/原稿/图示 → 结构化到对应位置；缺关键块 → 在笔记里写"【缺口：X】"，**不靠推测补**。

**Q4 禁区确认**（四条，来自课程边界 `00-底稿.md:291-328`）：
- 不写逐字稿（"笔记是为了备忘，而不是逐字稿"）
- 不用纯手写、不用"截图大法"、不以录音转文稿/AI 摘要一键直出当成品
- 层数不超过 3 层（复杂情况最多 4）
- 不加落地建议，不写"你可以用它做 X"

---

## 3 执行流程（六步）

| 步 | 输入 | 动作 | 产物 |
|---|---|---|---|
| **S1 定骨架** | 素材 + Q1/Q2 答案 | 定第一层的模块划分（L4 起必须 Topdown：第一层是模块名）；选定故事线类型并写下"本条笔记的故事线＝X" | 一级目录 |
| **S2 分点** | 素材正文 | 一个信息点拆成一行；有逻辑/顺序的用有序列表，没排序的用无序列表；**一律用编辑器自动列表** | 分点草稿 |
| **S3 分层** | 分点草稿 | 同主题归组，层级压到 2–3 层（上限 4）；超过 3 层就合并 | 结构稿 |
| **S4 加标题** | 结构稿 | 每行改成「**关键词：**正文」，同一层关键词字数尽量对齐 | 可扫读稿 |
| **S5 精简** | 可扫读稿 | 删语气词/插入语/解读/细节/修饰词；合并同类项；每行压到不换行 | 终稿 |
| **S6 自检** | 终稿 | 走 §5 清单 | 交付 |

**顺序铁律**：S2 之前不定骨架 → 后面必重排；S4 在 S5 之前 → 先加关键词再删字，否则关键词提炼不出来。

## 4 规则库（按档位；每条＝动作｜判据｜反例）

### L2 备忘（`00-底稿.md:218-227`）

- **1-1 文档工具**：用带"自动列表"的电子编辑器（Notion/飞书/石墨/Flomo/Obsidian 任一）。
  判据：全文没有手工敲的序号和空格缩进（Tab 缩进数＝0）。
  反例：手写 `1）　2）　3）` 后跟空格对齐。
- **1-2 记录工具**：开重点会/重点沟通时 100% 录音或录屏，笔记只做索引。
  判据：笔记里每条要点能指回录音时间点或原稿段落（同会话内可省，跨会话必须）。
  反例：只凭记忆补写，事后无法复核。
- **1-3 避免大段**：任一段落超过 2 行就拆成分点。
  判据：全文没有连续 3 行以上的散文段。
  反例："他说……然后……最后……"整段照搬。
- **1-4 逻辑分点**：一行一个信息点，不折行。
  判据：每一行的字符数 ≤ 编辑器一行宽度（肉眼不换行即达标）；有序/无序列表选对。
  反例：一行塞三件事；一个要点被折成两行。
- **1-5 只记备忘**：只写"未来用它时最少需要知道什么"，其余删。
  判据：随便挑一条，删掉任何一个词都会丢失信息。
  反例：保留语气词、插入语、点评、场景描述。

**L2 成品样例**（`00-底稿.md:226`，6 行即完稿）：
```
启动会参与：所有业务负责人。
短视频能力：一堂长期的必经之路。
规则1：Truman 牵头，全员下场。
规则2：12 月下旬开始，三个月的挑战。
规则3：自愿但严肃，不能轻易放弃。
官方支持：剪辑，选题培训。
```

### L3 协作（`00-底稿.md:229-234`）

- **2-1 产品意识**：按使用场景定形态——多人协作排版清晰、内容汇报用总分总、长期维护要清晰目录。
  判据：读者不看正文，只看目录就能说出这份笔记有几个部分。
  反例：平铺到底没有结构。
- **2-2 视觉美化**：加粗 / 颜色 / 底色 / # / 下划线 / emoji，只用来标重点。
  判据：装饰只出现在关键词或结论上；无整段彩色。
  反例：通篇花里胡哨，读者找不到重心。
- **2-3 两到三层**：分点保持 2–3 层，复杂最多 4 层。
  判据：最大缩进层级 ≤3（必要时 4）。
  反例：五层嵌套，"写的辛苦，读起来更累"。
- **2-4 信息密度**：每层"宽而充实"，合并同类项，必要时画表。
  判据：同一主题的信息不散落在两处以上；每行不是单词而是短语。
  反例：一行一个词，翻三屏没信息。
- **2-5 分点标题**：每行以「关键词：」开头，同层关键词字数尽量一致。
  判据：把所有正文遮住，左列关键词能对齐成一列且能读懂全篇。
  反例：没有关键词，"一片一片的，阅读压力巨大"。

### L4 内化（`00-底稿.md:236-241`）

- **3-1 升级设备**：用大屏记录（信息量更大、便于组合）。
  判据：同屏可见素材与成稿。
  反例：小屏来回切，边记边丢。
- **3-2 理故事线**：把内容塞进一条故事线，十类任选：时间线 / 操作步骤 / STAR / 问题解决 / 对比分析 / 关键要素 / 目标取舍 / 事实洞察 / 经典方法论 / 原创方法论。
  判据：能一句话说出"这份笔记的故事线是 X"。
  反例：按发言顺序原文堆叠。
- **3-3 Topdown**：从上往下拆模块，先有全局再有细节。
  判据：第一层标题全是模块名（不是内容句、不是时间点）。
  反例：第一层直接就是某人的某句话。
- **3-4 循环整理**：记录过程中实时整理，别等结束后一次性补。
  判据：成稿前至少做过一次结构调整（重排/合并/提层）。
  反例：记完直接交，结构是原始顺序。
- **3-5 提逻辑性**：把结构换成自己熟悉且能控制的思考框架。
  判据：不看原文，能用这份笔记把内容重讲一遍且逻辑连贯。
  反例：只做了排版美化，逻辑还是原文的。

### L5 思考（`00-底稿.md:243-248`）

- **4-1 问题驱动**：遇到值得的问题就单开一篇。
  判据：笔记标题是一个问题句（"为什么 X"「怎么做 Y」）。
  反例：标题是"XX 会议记录"。
- **4-2 立 flag**：自己写的字占比 ≥30%。
  判据：数一遍"自己判断/自己举例/自己质疑"的字数 ÷ 总字数 ≥ 0.3。
  具体动作：每本书 3–5 句精华；听课时写满一屏自己的思考；逼自己 20–50 个想法。
  反例：通篇摘抄，零判断。
- **4-3 广泛涉猎**：不只从课/书上取，留出脑力现场联想。
  判据：笔记里出现 ≥1 条素材之外的相关信息，并标注来源。
  反例：全部内容都在原文范围内。
- **4-4 深度洞察**：事实在上、判断在下；每条事实下面写自己的判断，再往下追 3–5 层规律。
  判据：每条事实下面都有"所以……"式的判断句。
  反例：只有事实和别人的观点。
- **4-5 长期迭代**：不求新，求体系完备、自洽。
  判据：同一主题存在多篇笔记且互相引用/更新。

### L6 萃取（`00-底稿.md:250-255`、`:193-195`）

- **5-1 现场提问**：前半段先不投屏偷记；必要时双人访谈（一人挡子弹）；提前定高目标。
  判据：访谈结束即完稿，无事后补记环节。
- **5-2 现场建模**：一边访谈一边匹配逻辑模型/分析框架，没有就现场建一个。
  判据：成稿里出现一个能复用的模型/框架，不是纯记录。
- **5-3 现场追问**：发现决策跳步 / 单一样本推理 / 与 20 分钟前矛盾，现场提出交叉验证。
  判据：笔记里 ≥1 处"追问 → 修正"的痕迹。
  反例：只记不追，把对方的话当结论。
- **5-4 现场反讲**：用新故事线把对方逻辑重讲一遍（Topdown、含重点与精彩点）。
  判据：对方确认"这就是我说的"。
- **5-5 一次到位**：访谈结束即笔记完稿，不做事后整理（地图 B 版作"一次到位"；正文原话"争取访谈结束，可以立即执行下一步"）。
  判据：交付时无"待补充"标记。

> 递进关系（原话）：插入提问记全 → 现场整理划重点 → 重构故事线 → 现场追问交叉验证 → 现场升华提炼金句 → 现场组织课程反讲。

### 通用结构规则（跨档位，2026-10-29 立）

> 起因：五步法笔记 v1 被判「符合清单体要求，但内容裁剪过多」，五要素全篇没解释。以下八条对 L2–L6 全体生效，与上面的档位规则叠加。

**G1 章节职责二分**

- 动作｜第 1 章（背景/本质/为什么学）由 Agent 归纳；第 2 章（课程内容）由课程提供，与大纲一一对应。
- 判据｜第 1 章搜不到课程正文段落，第 2 章搜不到 Agent 的判断（有则标「编者归纳」）。
- 反例｜把「这个怎么用 / 怎么自评 / 有什么限定」写进「本质是什么」。

**G2 骨架服从官方大纲**

- 动作｜课程笔记先取官方大纲（`course.detail` 的 detail 长图），章节号与子节缩进照抄。
- 判据｜第 2 章每个标题都能在大纲找到对应行；总分关系没有被拍平成并列。
- 反例｜用 Partner 的线性 structure 把「五层理解」排成与「建立框架」同级。

**G3 要素级覆盖（最高优先）**

- 动作｜课程核心若为 N 个要素，逐个回答六问：是什么／彼此关系／先后顺序／顺序错了会怎样／缺一个会怎样／怎么分析。
- 判据｜六问全有答案，或显式写「本课未讲」；只出现名字没有解释＝不合格。
- 反例｜五步法五要素只在名词章出现一句定义，全文不解释五个要素分别是什么。

**G4 叙事章节用 SCQA**

- 动作｜故事、案例、平行时空、实战复盘按「背景 → 冲突 → 问题 → 解法」拆，内部再清单化。
- 判据｜每段能读出「原来怎么做 → 撞上什么 → 要回答什么 → 换什么方法 → 下一段怎么变」。
- 反例｜把六个平行时空写成六组互不关联的短句。

**G5 方法章节用五问**

- 动作｜模型、层级、规则按「现象是什么 → 为什么做这一步 → 典型原因 → 解法 → 注意事项」拆。
- 判据｜五问齐全，缺的那问标「本课未讲」，不编。
- 反例｜「第一层理解」只写「要注意别过早细化」，没有现象与原因。

**G6 名词与引用准入**

- 动作｜名词章只收「课程单独命名并展开讲解、且不是过程性刻度」的概念；参考文献章只收真实外部引用。
- 判据｜五层理解／爬山地图／段位／及格线／平行时空等过程性构件不进名词章；讲师、抓取日期、uniqId 不进参考文献。
- 反例｜为凑格式硬写六节名词、写一节「讲师与抓取时间」。

**G7 原话与归纳分层**

- 动作｜原话加引号并标出处（`〔本课·章节〕`）；归纳章节开头一行「本节为归纳」；提炼结论标「编者归纳」。
- 判据｜随机抽 5 句，都能判定是课程原话还是我的归纳。
- 反例｜把自己的推论写成课程原话。

**G8 留白**

- 动作｜「落地应用&行动」「收获和思考」「作业」三节不代写。
- 判据｜三节要么空、要么只有一行说明（如「本课作业不纳入本笔记」）。
- 反例｜替用户写行动项、心得、作业计划。


**G9 编号用标准 Markdown 有序列表**（2026-10-29 立）

- 动作：主层写 `1. ` `2. ` `3. `，子层缩进两格写 `a. ` `b. `。
- 判据：全篇搜不到 `1、` / `a、` / `1) ` / `- ` / `* ` 开头的行；在编辑器里显示为真列表。
- 反例：写 `1、` → 显示成死文本；写 `a、` → 被编辑器接管重编号成 `1.` `2.`，编号错位（2026-10-29 用户截图实测）。

**G10 单一事实只出现一次**（2026-10-29 立）

- 动作：定稿前把第 1 章与第 2 章各节的主旨句并排列出，逐对比较。
- 判据：删掉后一条若不损失信息 → 判为重复，删后一条、把它独有的内容并进前一条；第 1 章不设「本课在体系中的位置」小节（系列位次、前置/延展课程、讲师履历属元信息）。
- 反例：1.1 已写「缺工具的两个现场」，2.0 又写一遍「为什么讲这个课」 → 用户判为冗余。

**结构关补充（2026-10-29）**

13. **盲读测试**：给没上过课的人读第 2 章，他能说出「讲了哪几件事、每件事的方法是什么」；说不出＝内容不足，回退补内容。

14. **要素级覆盖**：核心要素逐个过 G3 六问，没有「只有名字没有解释」的要素。
15. **大纲对齐**：第 2 章章节号与官方大纲逐条对应，总分关系未被拍平。

16. **两章不串**：第 1 章无课程正文，第 2 章无未标注的编者判断。
17. **编号与重复**：全篇无 `1、`/`a、` 编号；无跨章节重复（G9、G10）。

## 6 模板（L3 档可用，更高档在此基础上加模块/判断）

> 格式细则以 `yitang-checklist-notes` 技能的「格式硬规范」为准：编号用标准 Markdown 有序列表（主层 `1. `、子层缩进两格 `a. `）、每条之间空一行、标题不加粗。
> 本节只示范**模块内部该有哪些字段**。

```markdown
# <标题>

## 清单体笔记

### 一、<模块名：一句结论>

1. **结论：** <一句话>

2. **依据：** <要点>；<要点>

3. **待办：** <谁> / <做什么> / <何时>
```
